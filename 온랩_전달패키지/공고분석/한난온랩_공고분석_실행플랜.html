3. 선정되려면 — 심사기준 역산 전략

공고가 밝힌 심사기준은 ① 기업가정신 및 창업 목적 ② 팀 구성 및 경쟁력 ③ 시장성이며, "사업계획서의 각 요소를 중심으로 평가"합니다. 즉 서류심사(→30팀)는 사실상 사업계획서 싸움입니다.

③ 시장성 — 마켓게이트의 최대 강점

  • TAM/SAM/SOM 수치, 구독+연계수수료 수익모델, 수출바우처 진입전략이 이미 정리되어 있어 예비창업팀 평균 대비 완성도가 높습니다. 숫자의 근거(산식)를 한 줄씩 달아주는 것이 포인트.

② 팀 — 1인 팀의 약점을 정면 돌파

  • 심사위원의 예상 질문: "혼자서 개발이 되나?" → MVP 완성·특허 출원이라는 실물 증거 + 개발자 영입 협의 중 + 온랩 멘토링 활용 계획으로 답을 미리 깔아두었습니다.
  • 대면심사는 대표자 발표가 원칙(팀원 발표 시 불이익)이므로 1인 지원이 불리하지 않습니다. 팀원은 선정 후 변경 가능, 대표자만 변경 불가.

① 기업가정신 — 주최기관 맞춤 스토리

  • "수출 컨설턴트로 현장에서 문제를 반복 확인 → 기술로 해결하려 창업"이라는 서사가 창업 목적 평가에 직결됩니다.
  • 한난(에너지 공기업) 맞춤 포인트: 참가분야가 AX·GX·에너지인 만큼, "히트펌프·에너지 기자재 등 GX 품목 수출 중소기업을 온랩 기간 파일럿 세그먼트로 검증"하는 각도를 사업계획서 6장(자유주제)에 반영했습니다. 제품을 바꾸는 것이 아니라 초기 고객 세그먼트 하나를 주최기관 도메인에 맞춰 검증하겠다는 제안이며, 실제 실행 의사가 있을 때만 유지하세요.
경쟁 강도 참고: 서류에서 30팀, 최종 육성 15팀 내외 선발로 통상의 공공 액셀러레이팅 대비 문이 넓은 편입니다. 완성도 있는 서류라면 승산이 충분합니다.

6. auto_write 실행 결과 — 사업계획서 초안

요청하신 대로 깃허브 저장소의 BizPlan Injector 파이프라인을 실행해 온랩 양식 사업계획서 초안(DOCX + PDF 미리보기)을 생성했습니다.

실행 참고: pds2225/auto_write 저장소는 비공개(권한 없음)로 접근이 불가하여, 동일한 BizPlan Injector 엔진이 들어 있는 공개 저장소 pds2225/autowrite(auto_write로 통합되기 전 원본)를 클론해 실행했습니다. 실행 파이프라인: 온랩 양식 DOCX 생성 → inject.py --analyze 구조 분석 → content_onlab.json 작성(저장소의 마켓게이트 자료 기반) → inject.py 주입 → 검증(파란 안내문구 20개 자동 제거, 6개 섹션·3개 표 주입 확인).

초안에 반영된 내용의 출처

  • 저장소의 examples/company_info_sample.json, references/sample_business_plan.md (마켓게이트 사업 정보)
  • 온랩 공고문·참가신청서 원문 (양식 구조, 심사기준, 일정)
  • 온랩 맞춤 각색: 재창업·폐업 이력 서사는 제외(이 공고에서 불필요), 일정을 온랩 운영 일정(8~12월)에 재배치, 6장 자유주제에 한난 시너지 추가

제출 전 반드시 직접 확인할 사실관계 (초안은 저장소 자료 기준입니다)

  • 특허 출원번호(10-2026-0026207)·출원일, 파일럿 기업 수(12개사), 보육기관 수(8개사) 등 숫자 최신화
  • TAM 5,370억 / SAM 1,644억 / SOM 38억 산식과 근거 출처
  • 요금제(Basic 9.9만/Pro 29.9만), 개발 Phase 일정의 현재 상태
  • 표지 개요표의 대표자 성명(OOO 자리) 기입
  • 분량: 현재 약 6페이지 — "5페이지 내외" 요건에 맞게 검토하며 압축 (추천 압축 지점: 1-2 컨설팅 한계 절, 5-3 발전방안)

Windows에서 다시 생성하려면 (PowerShell)

cd 프로젝트폴더 ; pip install python-docx lxml ; python inject.py --template templates\온랩_사업계획서_양식.docx --content content_onlab.json --output output\온랩_사업계획서.docx

함께 보내드린 onlab_autowrite_kit.zip에 양식 DOCX·content JSON·양식 생성 스크립트가 들어 있습니다. JSON의 문구만 고쳐 다시 실행하면 서식이 유지된 채 내용만 바뀝니다.
