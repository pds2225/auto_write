# 사용자 지원사업 플레이북 (정본)

> 트리거: "업무 절차 알려줘", "그대로 실행", "하던 대로", "도보네비 카드", "이 신청서로 카드 바꿔",
> "뭐 신청했지", "아이템별로", "지원사업 목록".
> 신청 원장: `docs/clients/user_applications.md`. 목록 질문 스킬: `user-applications-memory`.
> 허브 라우팅은 `bizdoc-hub`와 같다. **이 파일은 순서·정본 파일·금지항**.

## 사용자가 나중에 물으면

1. **절차**면 아래 5단계를 짧게 말한 뒤 **그대로 실행**한다. 공고가 다르면 1지망·평가표만 갈아끼운다.
2. **뭐 신청했지 / 아이템별로**면 스킬 `user-applications-memory`와 `docs/clients/user_applications.md`를 읽고 **채팅으로만** 답한다.
3. 기업 사실은 `docs/clients/dobonevi_card.md`만 쓴다. 카드에 없는 숫자는 `[확인필요]`.
4. **Google Docs·드라이브 정리본을 만들지 않는다.** 사용자는 안 읽는다. 기억은 이 저장소 파일이다.

## 5단계 (그대로 실행)

```
0 공고 받기 → 1 분석 → 2 신청서 채움 → 3 검수 → 4 제출 → 5 발표(필요할 때만)
```

| 단계 | 하는 일 | 담당 |
|------|---------|------|
| 0 | 공고·양식을 `바탕 화면\지원사업_공고첨부_문서전용_20260625\번호_사업명\`에 둔다 | `공고첨부_받기.cmd` |
| 1 | 마감, 자격, **1지망 과제**, 평가표를 읽는다. 로컬/챌린지 혼동 금지 | `announcement-form-analysis` |
| 2 | **글을 새로 쓰지 않는다.** 카드·기존 신청서의 사실을 빈 칸에 옮긴다. 없으면 `[확인필요]` | `cross-form-submission` / `hwpx_submit` |
| 3 | 날조0. 목표값을 실적으로 쓰지 않음. fail이면 `_DRAFT` | `document-quality-orchestrator` / `self_diagnose` |
| 4 | 출력은 `제출완료\기업\번호_사업명\제출자료\`. **원본 공고 덮어쓰기 금지** | 파일 이동만 |
| 5 | 발표는 **신청서와 맞는 슬라이드 1파일만**. v2/v3를 동시에 들고 가지 않음 | 신청서 카드 대조 |

처음부터 본문을 새로 써야 하면 2단계만 `bizplan-orchestrator`로 바꾼다. "새 문장을 만들어야 하나?"로 판별.

## 파일 4칸 (섞지 말 것)

| 칸 | 역할 |
|----|------|
| 원본 | 공고·빈 양식. 읽기만 |
| 제출본 | 이미 낸 신청서. 다시 안 고침 |
| 발표본 | 오늘 쓸 슬라이드 **1개** |
| 초안 | 참고만. 발표장·제출 폴더에 안 넣음 |

트랙도 섞지 않음: **KICXUP** / **STAR-Exploration** / **auto_write 엔진 코드**.

- 프로그램: 산업단지 오픈이노베이션 **KICXUP 챌린지** (로컬 아님, STAR-Exploration 아님)
- 1지망: **한국케이블텔레콤 · 외국인 대상 서비스 일체** (사무공간 효율화 아님)
- 2지망: 폴라리스오피스 — **본편 7분에 넣지 않음**
- 평가: 기술20 / 사업20 / 협업20 / 팀15 / 실현15 / 확장10. TIPS·NEST 가점 없음(NEST=부)

## 금지 (이 사용자가 반복해서 막은 것)

- KASS/초정밀 **이미 구현**, RTK 상용, 지도 대비 N배, TAM/SAM, 네이버·카카오와 경쟁 구도
- "마지막 100m"
- KPI(300명, 90%+ 등)를 **현재 실적**처럼 쓰기 — 전부 **PoC 목표값**
- 개인 전화·이메일을 슬라이드에 넣기
- 원본 공고·제출본 덮어쓰기
- 기업명을 이 사업에서 도보네비로 바꿔 쓰기 — **제출 기업명 = 케이네비**, 브랜드는 도보네비
- 신청 목록·카드·절차를 Google Docs로 다시 정리해 주기 (사용자는 채팅으로만 물음)

## 카드 갱신

"이 신청서 기준으로 도보네비 카드 추가·변경" → `docs/clients/dobonevi_card.md`를 신청서에 **나온 사실만** 갱신한다. 신청서에 없는 칸은 지우지 않고 `[확인필요]`로 둔다. 전화·이메일은 이 저장소에 쓰지 않는다.
