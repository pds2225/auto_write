1. cross_form_fill 리포트: transcribed / needs_confirm / unmatched 확인
2. 기존 이력서 폴더(`01. 경영지도사 이력서`)와 성명·연락처·소속·학력 등 **사실값 대조**

4. `py -3.11 self_diagnose.py` 제출가능성 게이트
5. 한글 2022로 출력 HWP 열림 확인
