1. 재도전성공패키지 선정/수령 여부 확인 → 붙임2 작성 방향 결정 (없으면 공란)

3. 최종 DOCX → PDF 저장, 파일명: `마켓게이트_박다솜_사업계획서.pdf`
4. `공고원본/붙임2` HWP로 참가신청서 작성 (아래 §6 입력안) → PDF
5. 붙임3(개인정보 동의서)·붙임4(참가 서약서) 인쇄→서명→스캔 PDF
6. 주민등록등본 발급(정부24) — 주민번호 앞자리 포함 (연령 확인용 필수 증빙). 사실증명원·특허 출원 증빙·개발수행일지는 선택 증빙으로 추가 가능
7. 붙임2~5+증빙을 폴더 하나에 → ZIP 1개 (파일명 규칙: `팀명_대표자명_서류명`)
8. 구글폼 제출(금요일 오전) → 완료 화면 캡처 보관

## 7. 재실행 / 수정 방법
- 더블클릭: `실행하기.bat`
- PowerShell: `pip install -r requirements_onlab.txt` 후
  `python inject.py --template "templates\온랩_사업계획서_양식.docx" --content content_onlab.json --output "output\온랩_사업계획서_마켓게이트.docx"`
- 내용 수정: `content_onlab.json`의 `sections[].lines` 문구만 수정 (섹션 키 "1-1."~"6-1.")
- 표 수정: `table_rows`(팀 표=table 5, 일정 표=table 7), 개요표 셀=`table_cells`(table 0)

## 8. 주의 (파이프라인 규칙 — 다음 세션 필독)
- 양식의 **섹션 제목은 1×1 표(음영 바)**, 세부항목 제목은 `N-M.` 패턴 — 이 둘이 주입 경계(anchor)임. 양식에서 이 구조를 바꾸면 주입이 잘못된 범위를 지울 수 있음. 구조 변경 시 `build_onlab_template.py`를 수정해 양식을 재생성할 것.
- 양식의 파란색(0070C0) 안내문구는 주입 시 자동 삭제됨(정상 동작).
- `inject.py`는 실행 시 output 폴더의 기존 *.docx를 정리함 — 보관본은 다른 폴더에 복사해 둘 것.
- 페이지 수는 폰트 환경에 따라 ±1 변동. 공고 요건: 5페이지 내외, 12pt, 맑은 고딕/굴림, 줄간격 160%.
