# Bugbot 리뷰 언어·작성 규칙

## 언어 (필수)

- PR 리뷰 코멘트, 요약, 심각도 설명, 수정 제안, 리뷰가 제안하는 PR 제목·본문 문구는 **반드시 한국어**로 작성한다.
- 요청 원문: 「v_up처럼 코드리뷰나 pr 한글로나오게해줘」. 에이전트가 직접 쓰는 PR 본문도 `AGENTS.md` §9 를 따른다.
- 파일 경로, 심볼명, 코드 식별자, 커밋 해시, 로그/에러 메시지 원문은 영어 그대로 둬도 된다.
- 코드 인용 블록 안의 기존 코드는 원문 유지. 설명 문장만 한국어로 쓴다.

## 리뷰 초점

- 실제 버그, 보안, 회귀, 데이터 손상, 권한/인증 오류, 잘못된 기본값만 지적한다.
- 스타일·취향·단순 리팩터 제안은 하지 않는다.
- 문제마다 왜 문제인지와 구체적인 수정 방향을 짧게 제시한다.
