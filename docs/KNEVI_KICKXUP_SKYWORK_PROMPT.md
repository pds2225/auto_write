# K-네비 KICKXUP 9장 PPT — Skywork 이관 프롬프트

> Cursor는 python-pptx/PIL로 카드형 덱을 만들었고, 사용자는 같은 작업을
> **Skywork(시각 네이티브 도구)** 로 넘기라고 했다. 품질 낙제/불합격 판정이 아님.
> 엔진 코드와 무관. PPT 산출물은 git 금지.
>
> **사용:** Skywork Slides/PPT 모드에 **원본 9칸 스토리보드 이미지**를 첨부하고,
> 아래 블록을 그대로 붙여넣는다. 이미지가 없으면 제네릭 템플릿이 나온다.

```
역할: 너는 한국 스타트업 IR/피치덱 전문 디자이너다.
작업: 첨부한 9칸 스토리보드를 "한 장씩" 실제 발표 슬라이드로 재현한 뒤, 16:9 PPTX 1개 파일로 합쳐라.

[최우선 규칙]
1. 첨부 이미지가 정본이다. 레이아웃·일러스트·아이콘·카피·색감을 스토리보드에 최대한 가깝게 복제하라.
2. 제네릭 컨설팅 템플릿(파란 카드 나열, 아이콘 서클 5개만 있는 슬라이드)으로 바꾸지 마라. 스토리보드의 그림(폰 목업, 지도 점선, CU 랜드마크, 프로세스 화살표, 비교 박스)을 살려라.
3. 슬라이드는 정확히 9장. 표지/목차/감사 슬라이드 추가 금지.
4. 사실·숫자·고유명사를 창작하거나 바꾸지 마라. 아래 카피만 써라.
5. 언어: 한국어. 영문은 브랜드/기술용어만 (K-Nevi, GNSS, SBAS, KASS, AI, PoC, KPI, CPF, API, SMS, QR, KCT).
6. 산출물: 편집 가능한 PPTX, 와이드스크린 16:9 (1920×1080). 각 슬라이드는 발표용 완성본이어야 한다(작은 썸네일 9개를 한 장에 넣는 것 금지).
7. 폰트: 깨끗한 한글 산세리프(Pretendard / Noto Sans KR / 맑은 고딕). 본문 최소 18pt, 제목 32pt+.
8. 푸터를 모든 장에 동일하게 넣어라:
   2026 KICKXUP Challenge  |  K-Nevi  |  대표 박다솜
   오른쪽 장번호 01~09

[비주얼 시스템]
- 팔레트: 화이트 + 딥네이비 + 블루. 과한 그라데이션/3D/주식사진 금지.
- 스타일: 2026년 한국 IR, 클린, 인포그래픽. 여백을 충분히 둬라.
- 사진 대신 스토리보드와 같은 플랫 일러스트/아이콘/폰 목업을 써라.
- 한 슬라이드에 메시지는 1개. 글자를 빼곡히 채우지 마라.

────────────────────────────────
슬라이드 01 — 표지
제목: K-네비
부제: 길을 잘 못 찾는 보행자를 위한 위성항법
핵심가치: GNSS/SBAS 기반 보행자 정밀 경로 안내 + AI 경로 추천
비주얼(필수): 오른쪽 스마트폰 목업.
  - 말풍선: "CU를 지나 오른쪽 골목으로 들어가세요"
  - 지도에 파란 점선 경로, CU 편의점 아이콘
  - 칩: "다음 지점까지 135m"
한 줄: 지도 대체가 아니라, 보행자용 정밀 안내 레이어.

슬라이드 02 — 문제
제목: 기존 지도앱의 한계 — 보행자 길찾기 사각지대
아이콘 5개(스토리보드와 같은 배열):
1. 방향 혼동 — 출발 직후 어느 쪽으로 움직여야 할지 잡기 어렵다
2. 골목·출입구 — 복잡한 골목, 정확한 건물 출입구를 알아보기 어렵다
3. GPS 오차 — 고층빌딩(어반캐년)에서 위치가 점프하거나 어긋난다
4. 경로 이탈 — 잘못 들어갔을 때 즉시 인지·재안내가 없다
5. 언어 장벽 — 한국어 표지판·복잡한 상권은 외국인에게 더 어렵다
하단 한 줄: "목적지는 지도에 찍혀 있지만, 실제 길찾기는 어렵다."

슬라이드 03 — 해결
제목: 문제를 이렇게 풉니다
4단계 프로세스(화살표로 연결):
1. 위치 신뢰도 — GPS 흔들림/오차 분석, 보정 필요 순간 측정 (위성 아이콘)
2. 이탈 감지 — AI 경로 학습으로 방향 오류 즉시 포착 (돋보기/지도)
3. 음성 재안내 — 잘못된 방향 경고 + 최적 경로 재계산 (스피커)
4. 사진/랜드마크 안내 — 간판·건물 외관 시각 정보로 이해도 향상 (사진)
하단 비교(필수):
  기존: "100m 직진하세요"
  K-네비: "CU를 지나 오른쪽 골목으로 들어가세요"

슬라이드 04 — 기술 구조
제목: 기술 구조와 차별점
Input: GNSS/GPS · SBAS/KASS(위치 보정) · AI 경로 추천(추적/이탈) · 사진/랜드마크
Output: 위치 신뢰도 ↑ · 이동 신뢰도 ↑ · 도착 성공률 ↑
핵심 문장: 지도 대체가 아니라 보행자용 "Precision Guidance Layer"
레이아웃: 입력 → 중앙 레이어 → 출력 구조로 그려라.

슬라이드 05 — PoC 협력
제목: K-네비 × 한국케이블텔레콤(KCT) PoC
목표: 처음 방문하는 외국인 고객의 길찾기 문제 해결
워크플로(화살표):
  KCT 고객 접점(SMS/링크) → K-네비 다국어 안내(영/일/중) → 외국인 이용자(불안 감소, 도착 보장)
상호 이익:
  KCT: 외국인 UX 개선
  K-네비: 현장 데이터 + 대기업 레퍼런스

슬라이드 06 — 8주 계획 & KPI
제목: 8주 PoC 실행 계획 & KPI
타임라인:
  1–2주  현장 선정 / 데이터 구축
  3–4주  다국어 세팅 / QR 생성
  5–7주  외국인 이용자 모니터링
  8주    분석 / 최종 리포트
KPI 카드(숫자 크게):
  실사용자 300명
  거점 10곳+
  도착 성공률 90%+
  경로 이탈 30% 감소
  만족도 4.3 / 5.0

슬라이드 07 — BM & 확장
제목: 비즈니스 모델 & 확장 전략
수익 3개:
  1) B2B 위치 안내 구독
  2) 기업 API / 데이터 라이선스
  3) 지자체·행사 관광 패키지
확장 경로(왼쪽→오른쪽 또는 위→아래):
  KCT PoC(외국인) → 숙박(에어비앤비/소형호텔) → 관광(스마트시티) → 광역 B2B API

슬라이드 08 — 현재 단계
제목: 현재 단계 & 실행 역량
타임라인:
  ~2025 문제 정의 완료
  2026 상반기 대상지 선정
  2026 하반기 MVP & KPI 설계
현재: CPF(Customer-Problem-Fit) 검증 초기
강점 3개: 직접 MVP 개발 / 빠른 실행 / 외부 전문가와 린 협업

슬라이드 09 — 마무리
제목: K-네비 × 한국케이블텔레콤
비전: 위성항법과 AI로 외국인 보행자의 길찾기 실패를 줄이겠습니다.
공식(크게):
  KCT 고객 접점  +  K-네비 정밀 안내  =  방문 경험 향상
하단 프로세스: PoC → 검증 → 확장
```
