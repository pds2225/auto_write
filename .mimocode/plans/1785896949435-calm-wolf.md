# 필수/선택 서류 구분 + 불필요 서류 자동 정리 기능

## 목표
공고문에서 제출서류 목록을 추출해 필수/선택(해당시)으로 분류하고, 선택 서류는 기존 데이터로
판단 가능하면 자동 판단, 불확실하면 사용자에게 한 번에 질문, 불필요 서류는 통째로 삭제한 뒤
공란·빈표·빈문단을 정리한다.

## 현재 상태
- `announcement_analyzer.py`: `required_documents`를 문자열 리스트로 추출 (필수/선택 구분 없음)
- `folder_analyzer.py`: 양식 파일을 분석하지만 공고의 서류 목록과 매칭하지 않음
- `usage_acceptance.py`: `check_missing_required_documents()`가 있으나 config.required_documents에만 의존

### Step 1: 공고문에서 서류 목록을 구조화 추출

**파일:** `D:\auto_write\app\auto_write\services\announcement_analyzer.py`

#### 1a. AI 프롬프트 변경 (line 53-68)

`_AI_SYSTEM`의 `required_documents` 필드를 구조화:

```python
# AS-IS
'"required_documents": ["제출서류1", "제출서류2"]'

# TO-BE
'"required_documents": [\n'
'  {"name": "참가신청서 및 사업계획서", "required": true, "doc_type": "신청서", "hint": "붙임1"},\n'
'  {"name": "개인정보동의서", "required": true, "doc_type": "동의서", "hint": "붙임2"},\n'
'  {"name": "사실증명원", "required": false, "doc_type": "증빙", "hint": "증빙서류1, 해당시"}\n'
']'
```

- `required`: true = 공통 필수, false = "해당시"/"선택"/"해당자에 한함"
- `hint`: 공고 원문의 비고(붙임1, 증빙서류1 등)
- `doc_type`: 신청서/사업계획서/동의서/서약서/증빙/기타
